# Umar Hayat — Portfolio Website

A modern, responsive personal portfolio website built with **HTML5**, **CSS3**, and **Vanilla JavaScript**, featuring glassmorphic UI cards, dark/light theme switching, ambient particle motion, interactive project filtering, fixed-rate service packages, and custom portraits.

## Features

- **Dark & Light Mode Toggle**: Switch between deep dark mode and light mode with theme preference saved in `localStorage`.
- **Ambient Motion & Interactive Hero**: Includes glowing background orbs, a grid overlay, an animated particle network canvas, a typewriter role showcase, and 3D tilt interaction on the hero portrait stage.
- **Dual-Row Marquee**: Continuous counter-scrolling highlight ticker showcasing core skills and services.
- **Filterable Projects**: Filter project cards by category (`All Projects`, `Web & SaaS`, `AI Automation`, `E-Commerce`).
- **Fixed-Rate Packages & Inquiry Form**: Select a package to pre-fill the contact form subject, with toast notifications and a resume preview modal.
